# Vincent Rafael Garcia — Portfolio

A responsive personal portfolio made with HTML, CSS, and JavaScript. The website files are in `dist/` and require no build step.

Includes an animated introduction, a monochrome dotted background, an 80-hour work immersion experience at NYK-Fil Maritime E-Training, Inc., and the PWU QR Attendance featured project. Animations respect reduced-motion preferences.

## Finish personalizing

- Photo: place your image in `dist/`, then replace `.portrait-placeholder` in `dist/index.html` with an image that has an appropriate alt attribute. Keep its dimensions reserved in the stylesheet.
- Projects: update the featured project in `dist/index.html` to add more work.
- Contact: add your email or professional profile when ready. No contact details have been invented.

## Preview

Serve `dist/` with any static HTTP server, or open `dist/index.html` directly.

## Vercel

Import this repository with its root directory unchanged. `vercel.json` selects the static `dist/` output without a build command. Vercel must serve `dist/index.html` as the site's home page.

The administrator-login project image is a static preview rendered from the application's markup and styles. The attendance application's source, backend, database, and credentials are not included.
